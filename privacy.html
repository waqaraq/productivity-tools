Privacy Policy — Reusable MCQ Quiz Builder

Effective date: [EFFECTIVE DATE]

Reusable MCQ Quiz Builder is a Google Forms Editor add-on designed to help educators create weighted MCQ assessments, grade responses, maintain assessment results and generate Outcome-Based Education reports.

Information processed by the add-on

The add-on may process information entered by the teacher, including University, Department, Course Name, Course Code, teacher name, CLO, PLO, Bloom taxonomy, problem statements, rubrics, assessment settings, questions and answer options.

Depending on the Google Form settings selected by the teacher, student response information may include Student Name, Registration Number, email address, timestamp, selected answers, scores, totals and percentages.

How Google user data is used

Google user data is used only to provide the visible functions of the add-on, including creating and configuring the current Google Form, grading assessment responses, maintaining the Results workbook, performing assessment analysis and generating teacher-requested reports.

Where data is stored

  • Student responses remain in the Google Form controlled by the user.
  • Results are stored in the Google Sheets workbook created in the user's Google account.
  • Assessment configuration and technical mappings required by the add-on are stored using Google Apps Script properties associated with the assessment workflow.
  • The developer does not operate a separate application database containing copies of student assessment responses.

PDF reports

Complete OBE PDF reports are generated in the user's browser when the user explicitly requests an export. Once downloaded, the report is stored on and controlled by the user's device.

Institutional logo

A logo selected by the user is processed locally and stored in browser local storage. It is not intentionally uploaded to a developer-operated server.

Excel files

Excel question files are parsed in the user's browser. The original Excel file is not intentionally uploaded to a developer-operated server.

Third-party software libraries

The add-on uses client-side software libraries supplied through HTTPS content-delivery networks, including SheetJS, jsPDF, jsPDF-AutoTable and Chart.js. These libraries provide Excel parsing, PDF generation, tables and charts. Assessment data is not intentionally transmitted to those providers by the application. The providers may receive ordinary web-request information such as IP address, browser information and request time when library files are downloaded.

Sharing, sale and advertising

The developer does not sell Google user data or student data, use such data for advertising, provide it to data brokers or use it for credit decisions. The add-on contains no advertising.

Artificial intelligence

The current application does not send student assessment information or Google user data to external AI models and does not use that information to train AI systems.

Human access

The developer does not routinely access teacher or student assessment records. Human access would occur only when explicitly authorized by the user for support, where necessary to investigate abuse or security issues, or where legally required.

Security

The add-on uses Google OAuth authorization, HTTPS APIs, restricted API endpoints and least-privilege design practices. Users remain responsible for controlling access to their Google Forms, spreadsheets and downloaded PDF reports.

Retention and deletion

Data stored in Google Forms and Google Sheets remains subject to the user's Google account settings and deletion controls. Users may delete their Forms, Results workbooks and downloaded PDFs at any time. Browser-stored logo data can be removed by clearing browser/site storage.

Users may uninstall the add-on and revoke its Google account authorization through their Google account security settings.

Educational and student information

Reusable MCQ Quiz Builder is intended as an educator productivity tool. Students are not required to install or authorize the add-on. Teachers and institutions are responsible for ensuring that they have the appropriate authority, notices and consents required when collecting student information.

Google API Services User Data Policy

Reusable MCQ Quiz Builder's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including applicable Limited Use requirements.

Changes to this policy

This policy may be updated when the functionality or data practices of the add-on change. Material changes will be reflected on this page before the changed data use is introduced.
