Setup Guide — Reusable MCQ Quiz Builder

  1. Install Reusable MCQ Quiz Builder using the supplied Google Workspace Marketplace link.
  2. Open the Google Form you want to use.
  3. Open Reusable MCQ Quiz Builder from the Google Forms add-on interface.
  4. Enter University, Department, Course Name, Course Code, Teacher, CLO, PLO, Bloom level and Problem Statement.
  5. Configure scoring, rubric and quiz settings.
  6. Download the Excel question template.
  7. Enter the question statement and Options A–D for each question.
  8. Upload the completed Excel file.
  9. Select Build / replace current form.
  10. Student submissions are graded and transferred to the Results workbook.
  11. Use Open results workbook to review results.
  12. Use Export complete OBE PDF report for the consolidated OBE record.

Scoring

By default, Option A = 4, B = 3, C = 2 and D = 1. These values can be changed in the add-on while preserving descending weights.

Results and OBE reporting

The Results workbook is automatically updated when responses are submitted. The OBE PDF is generated only when explicitly exported by the teacher.
